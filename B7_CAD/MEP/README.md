# B7 機電設備配置圖（PDF 套入 DWG 底圖）

| 檔案 | 內容 |
|---|---|
| `B7_插座設備配置圖.dxf` | 1F～3F 插座、專用插座、電熱水器/揚水泵出線口、分電盤、電表、接地、分路配線 |
| `B7_照明設備配置圖.dxf` | 燈具、壁燈、排風機、接線盒、開關(屬性 S/S3/SS3/SF…)、照明配線 |
| `B7_電信設備配置圖.dxf` | TC/TVC 出線口、電信箱、出線口編號、電話/網路/有線電視配管 |
| `B7_給水設備配置圖.dxf` | 冷/熱水管、給水出口、電能熱水器、水表組、揚水泵 |
| `B7_排水設備配置圖.dxf` | SP/WP/VP/RP/ACP 管、地板落水頭、清潔口、冷氣排水口、陰井、VTR |
| `B7_機電圖例表.dxf` | 五系統總圖例表（圖例、名稱、說明、數量） |
| `B7_機電設備配置圖_預覽.pdf` | 20 頁預覽（各系統 1F/2F/3F + 圖例表） |

每張配置圖 = 使用者提供的 DWG 底圖（1F/2F/3F 三個圖框，S=1/100，單位 cm）＋ 該系統機電資料 ＋ 右側圖例表圖框。

## 製圖方式
- PDF 為 CAD 列印之向量檔：以灰色建築線與 DWG 底圖自動配準（三層共用比例），其餘四份 PDF 以相同建築內容精確換算。
- 相同符號以範本比對找出所有實例（含旋轉），換成標準圖塊（BLOCK）；迴路編號、開關型式、出線口編號為圖塊屬性。
- 文字依原圖判讀後重新輸入為可編輯 TEXT（字型：微軟正黑體）。
- 管線、立管箭頭、引線、導線根數短劃等，以原圖幾何轉為聚合線，依系統分圖層。

## 圖層
- 電：`E-插座`、`E-插座-分路配線`、`E-幹線`、`E-盤箱`、`E-接地`、`E-迴路編號`、`E-照明`、`E-照明-配線`、`E-照明-開關`、`E-註記`
- 電信：`T-電信`、`T-有線電視`、`T-電信箱`、`T-配管-電話網路`、`T-配管-有線電視`、`T-註記`
- 給水：`P-給水-冷水`、`P-給水-熱水`、`P-給水-設備`、`P-給水-水表`、`P-給水-套管`、`P-給水-註記`
- 排水：`P-排水-汙水SP`、`P-排水-雜排水WP`、`P-排水-通氣VP`、`P-排水-雨水RP`、`P-排水-冷氣ACP`、`P-排水-VTR`、`P-排水-套管`

## 備註
- 輸出為 DXF（AutoCAD 可直接開啟，另存新檔即為 DWG）。
- `src/` 為處理程式（配準、範本比對、圖塊、出圖），`registration.json` 為各 PDF 各樓層之轉換參數。
