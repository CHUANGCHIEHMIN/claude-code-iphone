# 法人籌碼選股（台股三大法人 × 永續 × 未來性 × 投行評等 × 量增）

每個交易日自動產出一份選股報告，並以手機友善的網站呈現（可在 iPhone Safari「加入主畫面」當 App 使用）。

- **網站**：`docs/`（GitHub Pages 靜態網站，讀取 `docs/data/` 的 JSON）
- **資料管線**：`screener/`（Python 3.12，標準庫＋Anthropic SDK）
- **排程**：`.github/workflows/daily-report`，每天 20:00（台北）執行（GitHub 排程常延遲 30～60 分鐘）並把報告 commit 回 repo；休市日已有報告會自動略過
- **回測**：`.github/workflows/backtest.yml`，每週六 10:00（台北）補歷史資料並重跑回測，也可手動執行

## 選股流程

| 步驟 | 內容 | 資料來源 |
|---|---|---|
| 1 候選池 | 上市＋上櫃普通股（排除 ETF／ETN／權證／特別股／存託憑證），近 5 個交易日三大法人買賣超股數 × 當日收盤價逐日加總，取買超金額前 50 名。另列外資、投信 5 日買賣超，以及「買超金額 ÷ 5 日成交值」（≥10% 標「法人主導」） | 證交所 T86、MI_INDEX；櫃買中心三大法人買賣明細、上櫃行情 |
| 2A 永續 | 公司治理評鑑前 20%、臺灣永續指數／富時台灣 ESG 成分股、MSCI ESG A 以上（符合任一） | `config/sustainability.json` 手動清單，或 Claude 網路搜尋（須附來源網址） |
| 2B 未來性 | 成長產業主題（AI 伺服器、先進製程封裝、矽光子、散熱、重電儲能、機器人、低軌衛星、資安、生技新藥），或近 3 個月月營收年增率皆為正 | `config/themes.json`、公開資訊觀測站月營收、Claude 網路搜尋 |
| 2C 投行 | J.P. Morgan、BofA、Morgan Stanley、Goldman Sachs 近 3 個月評等（列出券商／評等／目標價／日期／連結；負面也列） | 自動搜尋 Google 新聞標題擷取（免費）；有 API 金鑰時再加上 Claude 網路搜尋 |
| 入選 | A、B 皆符合，C 不是「只有負面評等」，且非處置股；最多 20 檔 | 證交所、櫃買中心處置有價證券公告 |
| 3 量增 | 量增比＝5 日均量 ÷ 20 日均量，入選股依此排序，≥1.2 標「量增」 | 同步驟 1 |
| 4 報告 | 摘要、精選表、候選池前 20 名對照表、個股新聞＋當日國內外科技新聞、資料限制、Sources | 以上全部；科技新聞免金鑰：Google 新聞 RSS 國內／國外各 10 則，同一事件需 2 家以上媒體報導才收錄，外文標題以 Google 翻譯轉繁中並附原文與所有來源連結 |

| 5 訊號 | 每檔入選股標示隔日開盤的進場訊號：**可進場**（收盤站上上彎的 20 日均線，且突破前 20 日高點並量增；拉回 10 日均線的進場方式可在設定中開啟，預設關閉）、**觀察**、**過熱**（5 日漲幅 >15%、高於 20 日均線 >15%、融資 5 日增加 >10% 或注意股）、**排除**（處置股）；另有 0–100 的**綜合分數**（買超占成交值、投信買超占成交值、5 日買超天數、量增比的百分位平均，C 正面 +5／僅負面 −5） | 近 26 個交易日行情 |
| 6 模擬持股 | 依「可進場」訊號（綜合分數高者優先）隔日開盤買進；停損＝進場價−2×ATR（最多 −8%），收盤曾獲利 10% 後停損上移到成本（保本）、外資＋投信連 5 日賣超出場、20 日未獲利 3% 出場；每筆風險 1%、最多 8 檔、同產業最多 3 檔；加權指數低於 60 日均線時不新增持股（強勢時每天最多 3 檔）；加權指數收盤距 20 日高點跌 15% 以上起的 5 個交易日為「大跌買點」，不論強弱勢每天買入選清單綜合分數最高、未過熱的 3 檔，不要求突破訊號 | `config/strategy.json` |
| 7 績效 | 每份報告的入選股：隔日開盤買進後 1／5／10／20 日報酬（扣成本）、勝率、相對加權指數的超額報酬，並依量增、法人主導、新進榜、訊號、分數分組 | `data/history/` 每日快照 |

另外補充：本益比（證交所 BWIBBU／櫃買本益比）、外資持股比率 5 日變化（MI_QFIIS／櫃買僑外資持股）、融資餘額 5 日增減（MI_MARGN／櫃買融資融券）。
查不到的欄位一律顯示「—」，並寫入「資料限制說明」。

## 回測與歷史資料

- `data/history/`：每個交易日一個 `YYYY/YYYY-MM-DD.csv.gz`（上市＋上櫃普通股的開高低收、成交量值、三大法人買賣超），加上 `taiex.csv`（加權指數，也是交易日曆）與 `revenue/`（月營收年增率）。每日報告會自動補進最近 5 個交易日。
- **Actions → backtest → Run workflow**：先回補歷史資料（預設 3 年，第一次約 1～2 小時，未完成的下次會接著補），再執行回測並把結果寫到 `docs/data/backtest.json`、`docs/reports/backtest.md`，網站「績效」頁會顯示。之後每週六 10:00 自動更新。
- 回測內容：
  1. **選股規則比較**：現行規則、候選池全部 50 檔、只看 B、依買超占比排序、依綜合分數排序、全市場買超占比候選池、加上量增／投信連買／排除過熱／可進場訊號等，各自隔日開盤買進持有 5／10／20 日的平均報酬、勝率與超額報酬，分成調參期與驗證期（分界在 `config/strategy.json` 的 `backtest.split`）。
  2. **策略模擬**：完整出場規則 vs 停損＋固定持有 10 日 vs 固定持有 10 日，含總報酬、年化、最大回撤、賺賠比。
- 限制：條件 C（新聞）與處置／注意股無法回測；條件 A 與 B 主題表用的是現在的名單（有後見之明）；融資沒有存歷史。
- 本機：`python -m screener.backfill --years 3`、`python -m screener.backtest`。

## 調整策略參數

`config/strategy.json` 集中所有進出場、過熱、大盤濾網、部位、成本與回測參數，每個區塊都有中文說明。改完後，下一次每日報告與回測就會套用。建議每次只改一個參數，並比較回測的「驗證期」結果再決定是否保留。

## 推播通知（選用）

設定 Actions secrets `TELEGRAM_BOT_TOKEN`（向 @BotFather 申請）與 `TELEGRAM_CHAT_ID`，每日報告產出後會傳送「明日買進／賣出」與模擬帳戶摘要到 Telegram；可另設 Actions variable `SITE_URL`（網站網址）附在訊息最後。未設定時自動略過。

## 一次性設定

1. **合併到 main**（排程只在預設分支執行）。
2. **開啟 GitHub Pages**：Settings → Pages → Build and deployment → Source 選 *Deploy from a branch*，Branch 選 `main`、資料夾 `/docs`。網址會是 `https://<帳號>.github.io/<repo>/`。
3. **設定 API 金鑰**（啟用條件 A／C 與新聞查證）：Settings → Secrets and variables → Actions → New repository secret，名稱 `ANTHROPIC_API_KEY`。
   未設定時仍會產出報告，但永續性（除手動清單外）、投行評等、個股新聞會標示「未查證」，通常不會有個股入選。
4. （選用）Actions *Variables*：
   - `SCREENER_MODEL`：預設 `claude-opus-5-5`
   - `SCREENER_MAX_RESEARCH`：每日最多網路研究幾檔（預設 30；候選池前 20 名＋其餘通過條件 B 者）
5. 手動執行：Actions → daily-report → Run workflow（可指定日期、或勾選「不呼叫 Claude API」）。

> 成本提醒：每檔個股研究約使用 8 次網路搜尋，30 檔每日約數美元（依實際 token 用量而定）。可調低 `SCREENER_MAX_RESEARCH` 或改用較便宜的模型。同一交易日重跑時，已研究過的個股會使用 `docs/data/cache/` 快取。

## 本機執行

```bash
pip install -r requirements.txt
python -m pytest -q tests                  # 離線測試（使用與官方格式相同的假資料）
python -m screener --no-llm                # 只跑官方數據步驟
ANTHROPIC_API_KEY=... python -m screener   # 完整報告
python -m http.server -d docs 8000         # 開 http://localhost:8000
```

`python -m screener --date 2026-10-22` 可指定基準日；遇假日會自動往前找最近交易日（例如 2026-10-23 休市）。

  - **更新方式**：臺灣永續指數每年 6 月、12 月定期審核，生效後到 Actions → **update-sustainability** → Run workflow，會重新下載並更新名單。

## 資料限制

- 買超金額為「買賣超股數 × 當日收盤價」估算，非實際成交均價；「外資」為外資及陸資（含外資自營商）。
- 投行評等僅能取自公開新聞報導，券商報告本身不公開，可能遺漏或日期落差。
- 證交所／櫃買中心網站改版時解析可能失效；`tools/probe.py` 可快速檢查各端點目前的回應格式（Actions → probe-endpoints）。
- 本專案為資料整理工具，不構成投資建議。
